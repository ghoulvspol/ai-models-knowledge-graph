# Arena

Chatbot Arena 是由 LMSYS（Large Model Systems Organization）运营的人类偏好排名平台。用户与两个匿名模型对话，投票选出更好的回答，通过 Elo 评分系统计算模型排名。

## 评测机制

- **匿名对战**：用户不知道正在评测哪个模型
- **人类投票**：用户选择更好的回答或打平
- **Elo 评分**：类似国际象棋的排名系统
- **样本量**：超过 200 万次人类投票（截至 2025 年）

## 排名优势

| 优势 | 说明 |
|------|------|
| 人类偏好 | 直接反映用户真实偏好 |
| 动态更新 | 实时更新排名 |
| 难以刷分 | 匿名机制防止针对性优化 |
| 覆盖全面 | 包括推理、创意、编码等多种场景 |

## 分类排名

Arena 还提供分类排名：
- **编码**：代码生成和调试能力
- **数学**：数学推理能力
- **创意写作**：文学创作能力
- **长文本**：长上下文处理能力
- **多语言**：非英语语言能力

## 行业影响

Arena 已成为 AI 行业最受认可的评测之一：
- 模型发布时报告 Arena 排名已成为行业惯例
- 推动了模型在实际用户体验上的优化
- 揭示了学术评测与用户体验之间的差异
- [[OpenAI]]、[[Anthropic]]、[[Google DeepMind]] 等均重视 Arena 排名

## 局限性

- 用户群体可能有偏（技术背景为主）
- 对话长度和类型可能影响评估
- 短期内的排名波动可能不代表真实能力差异
- 无法评估专业领域的准确度

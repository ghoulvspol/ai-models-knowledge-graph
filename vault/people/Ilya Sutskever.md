# Ilya Sutskever

Ilya Sutskever 是深度学习领域的先驱研究者，[[OpenAI]] 联合创始人和前首席科学家。2024 年离开 OpenAI 后创立了 Safe Superintelligence Inc.（SSI），专注于安全的超级智能研究。

## 学术背景

- **导师**：[[Geoffrey Hinton]]（多伦多大学）
- **博士学位**：多伦多大学计算机科学（2013）
- **Google Brain**：2012-2015 年，参与 AlexNet 等开创性工作

## 关键贡献

| 贡献 | 说明 |
|------|------|
| AlexNet | 2012 年 ImageNet 竞赛的突破性深度学习模型（与 Hinton、Krizhevsky） |
| Sequence-to-Sequence | 机器翻译的基础架构 |
| [[Transformer]] 参与 | 对注意力机制的早期探索 |
| GPT 系列 | [[OpenAI]] GPT 系列的核心推动者 |
| [[Scaling Laws]] | 推动"规模即智能"的研究方向 |
| [[RLHF]] | 领导语言模型对齐研究 |

## 在 OpenAI 的角色

Ilya 是 [[OpenAI]] 创始团队的核心成员：
- 2015 年与 [[Sam Altman]]、Elon Musk 等共同创立 OpenAI
- 担任首席科学家（Chief Scientist），领导研究方向
- 推动了从 GPT-1 到 GPT-4 的技术路线
- 2023 年参与了对 [[Sam Altman]] 的解职决定
- 2024 年 5 月离开 OpenAI

## SSI（Safe Superintelligence Inc.）

2024 年创立的公司，专注于：
- 安全的超级智能系统研究
- 将安全作为首要目标而非事后考虑
- 团队包括前 OpenAI、[[Google DeepMind]] 研究员
- 已获得 10 亿美元融资

## 思想观点

Ilya 认为：
- 规模化是通往 AGI 的关键路径
- 超级智能的安全问题必须在开发过程中而非之后解决
- 当前的大模型已经展现出令人惊讶的涌现能力
- 对齐问题是 AI 安全的核心挑战

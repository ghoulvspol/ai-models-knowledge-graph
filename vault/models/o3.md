# o3

[[o3]] 是 [[OpenAI]] 于 **2025年1月发布预告、2025年4月正式发布** 的推理模型，是 [[o1]] 系列的重大升级，在数学、编程和抽象推理任务上达到新高度。

## 核心参数

| 指标 | 数值 |
|------|------|
| 发布预告 | 2025年1月（ARC-AGI 测试结果公布） |
| 正式发布 | 2025年4月16日 |
| 上下文窗口 | 200K tokens |
| 最大输出 | 100,000 tokens |
| 架构 | [[Transformer]] + 高级推理链 |
| API 定价 | $10 / 1M input，$40 / 1M output |

## 核心突破：ARC-AGI

o3 最引人注目的成就是在 [[ARC-AGI]]（抽象推理挑战）上的表现：

| 配置 | 分数 | 备注 |
|------|------|------|
| ARC-AGI（高计算） | **87.5%** | 大幅超越前记录（55.5%） |
| ARC-AGI（低计算） | 75.7% | 效率模式 |

这一成绩意义重大，因为 [[ARC-AGI]] 被认为是衡量 AI 抽象推理能力的关键基准，此前没有任何模型超过 55%。

## 推理机制

o3 的推理能力较 [[o1]] 有质的飞跃：
- 更长、更深入的内部推理链
- 能够进行自我验证和纠错
- 在复杂多步骤问题上保持推理一致性
- 推理计算量可动态调整，根据问题复杂度分配资源

## 与前代对比

| 模型 | ARC-AGI | MATH | GPQA | 推理深度 |
|------|---------|------|------|----------|
| o3 | 87.5% | 97.9% | 83.3% | 最深 |
| [[o1]] | 32% | 96.4% | 78.0% | 深 |
| [[GPT-4o]] | 5% | 76.6% | 53.6% | 标准 |

## 行业影响

o3 在 [[ARC-AGI]] 上的突破引发了广泛讨论：
- 证明了 [[Scaling Laws]] 在推理计算维度上的有效性
- 推动了 [[AI Safety]] 领域对高级推理能力的风险评估
- 促使 [[DeepSeek]]、[[Google DeepMind]] 加速推理模型研发
- 重新定义了"通用智能"的评估标准

## 同期产品

o3 发布时与 [[o4-mini]] 一同推出，形成推理模型的双线布局：o3 面向最高精度场景，[[o4-mini]] 面向效率优先场景。

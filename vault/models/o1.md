# o1

[[o1]] 是 [[OpenAI]] 于 **2024年9月12日** 发布的推理模型系列，首次将 [[Chain of Thought]] 推理作为核心能力，开创了"推理模型"这一新品类。

## 核心参数

| 指标 | 数值 |
|------|------|
| 发布日期 | 2024年9月12日（preview） |
| 上下文窗口 | 128K tokens（o1-preview），200K tokens（o1） |
| 最大输出 | 32,768 tokens（o1），65,536 tokens（o1正式版） |
| 架构 | [[Transformer]] + 推理链 |
| API 定价 | $15 / 1M input，$60 / 1M output（o1-preview） |

## 架构与训练

o1 系列的核心创新在于"推理时计算"（inference-time compute）：模型在生成最终答案前，会进行一段内部的 [[Chain of Thought]] 推理过程，消耗额外的计算资源来提升推理质量。

训练方法结合了大规模 [[RLHF]] 和强化学习，使模型学会了"思考再回答"的模式。推理过程对用户不可见，但会消耗大量 tokens。

## Benchmark 表现

| 基准测试 | o1-preview | o1 正式版 | 备注 |
|----------|-----------|----------|------|
| [[MATH]] | 94.8% | 96.4% | 竞赛级数学 |
| [[GPQA]] | 73.3% | 78.0% | 研究生级科学问答 |
| [[HumanEval]] | 92.4% | 94.0% | 代码生成 |
| [[MMLU]] | 91.8% | 92.3% | 多领域知识 |
| 编程竞赛（Codeforces） | 89th percentile | 93rd percentile | 竞赛编程 |
| ARC-AGI | - | 32% | 抽象推理 |

## 推理能力特点

- **数学推理**：在 [[MATH]] 上首次突破 94%，接近人类数学竞赛选手水平
- **科学推理**：[[GPQA]] 超过 73%，超越大多数领域专家
- **编程竞赛**：Codeforces 评分达到 1807 ELO，相当于专业程序员水平
- **推理成本**：每次推理消耗大量 tokens，成本远高于传统模型

| 版本 | 定位 | 定价 |
|------|------|------|
| o1-preview | 早期预览版 | $15/$60 per 1M tokens |
| o1-mini | 轻量推理版 | $3/$12 per 1M tokens |
| o1 正式版 | 完整推理版 | $15/$60 per 1M tokens |

## 行业影响

o1 的发布标志着 AI 行业从"更大模型"转向"更多推理计算"的范式转变。[[DeepSeek R1]]、[[Claude Opus 4]] 等后续模型都采用了类似的推理时计算策略。

o1 证明了一个关键假设：在推理阶段投入更多计算资源，可以显著提升模型在复杂任务上的表现，这与 [[Scaling Laws]] 的传统训练时扩展形成互补。

## 局限性

- 推理过程不透明，用户无法看到思考链
- 延迟高，简单任务也会触发深度推理
- 成本显著高于非推理模型
- 部分简单任务上表现不如 [[GPT-4o]]

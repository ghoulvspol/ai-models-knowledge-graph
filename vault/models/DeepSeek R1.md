# DeepSeek R1

[[DeepSeek R1]] 是 [[DeepSeek]] 于 **2025年1月20日** 发布的开源推理模型，是首个在推理能力上与 [[o1]] 匹敌的开源模型，引发了全球 AI 行业的震动。

## 核心参数

| 指标 | 数值 |
|------|------|
| 发布日期 | 2025年1月20日 |
| 总参数 | 671B（基于 [[DeepSeek V3]]） |
| 激活参数 | 37B |
| 上下文窗口 | 128K tokens |
| 最大输出 | 65,536 tokens |
| 架构 | [[Transformer]]，[[MoE]] + 推理链 |
| 开源许可 | MIT License |

## 架构与训练

DeepSeek R1 基于 [[DeepSeek V3]] 的 [[MoE]] 架构，通过纯强化学习训练获得推理能力。

训练方法（创新性）：
- **纯 RL 训练**：不依赖监督微调（SFT），直接通过强化学习训练推理能力
- **Group Relative Policy Optimization (GRPO)**：创新的 RL 算法，无需 critic 模型
- **冷启动数据**：少量高质量推理示例引导 RL 训练
- **拒绝采样**：从 RL 模型中筛选高质量推理轨迹
- 推理过程对用户可见（透明的 [[Chain of Thought]]）

## 核心突破

### 纯 RL 推理训练
DeepSeek R1 最大的创新在于证明了"纯强化学习"可以训练出强大的推理能力，无需大规模的监督微调数据。这一发现：
- 降低了推理模型的训练门槛
- 证明了 RL 在推理能力培养上的有效性
- 挑战了 [[RLHF]] 需要大量人工标注的范式

### 开源推理模型
作为首个与 [[o1]] 匹敌的开源推理模型，DeepSeek R1 打破了推理模型的闭源垄断：
- MIT 许可，完全开放商用
- 支持本地部署和 [[Fine-tuning]]
- 推理链透明可见

## 行业影响

DeepSeek R1 的发布被称为"AI 的 Sputnik 时刻"：
- 直接导致 [[NVIDIA]] 股价单日下跌 17%
- 证明了中国 AI 团队可以在推理领域与美国竞争
- 推动了开源推理模型的爆发（[[Qwen 3]]、Llama 等后续模型均加入推理能力）
- 挑战了"更多资本 = 更好模型"的行业假设
- [[Sam Altman]] 称其"令人印象深刻"

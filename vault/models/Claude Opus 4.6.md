# Claude Opus 4.6

[[Claude Opus 4.6]] 是 [[Anthropic]] 发布的旗舰推理模型，作为 [[Claude Opus 4.5]] 的后继者。它是首批支持 1M token 上下文窗口的 Opus 模型之一，并支持扩展思考（Extended Thinking）。现已标记为 Legacy 模型。

## 核心参数

| 指标 | 数值 |
|------|------|
| API ID | claude-opus-4-6 |
| 上下文窗口 | 1M tokens |
| 最大输出 | 128k tokens |
| 扩展思考 | 是 |
| 状态 | Legacy |
| API 定价 | $5 / 1M input，$25 / 1M output |

## 核心特性

### 1M 上下文
[[Claude Opus 4.6]] 将上下文窗口从 [[Claude Opus 4.5]] 的 200K 大幅扩展至 1M tokens，能够处理更长的文档和更大的代码库。

### 扩展思考
支持扩展思考（Extended Thinking）模式，在复杂推理任务上可显著提升准确率。

### 128k 输出
最大输出从 64k 扩展至 128k tokens，适合生成长文档和进行大规模代码重构。

## 产品定位

[[Claude Opus 4.6]] 已被 [[Claude Opus 4.7]] 和 [[Claude Opus 4.8]] 逐步取代，现为 Legacy 模型。对于新项目，建议使用 [[Claude Opus 4.8]]。

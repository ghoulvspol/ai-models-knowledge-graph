# Claude Opus 4.1

[[Claude Opus 4.1]] 是 [[Anthropic]] 发布的旗舰推理模型，API ID 为 claude-opus-4-1-20250805。作为 [[Claude Opus 4]] 之后的首个小版本迭代，它在定价和能力上有所调整。现已标记为 Legacy 模型。

## 核心特性

### 继承 Opus 4 架构
[[Claude Opus 4.1]] 基于与 [[Claude Opus 4]] 相同的架构，在推理能力和对齐质量上进行了微调优化。

### 高端定价
与 [[Claude Opus 4]] 保持相同的 $15/$75 定价档位，反映其作为高端旗舰模型的定位。

## 产品定位

[[Claude Opus 4.1]] 是 [[Claude Opus 4]] 和 [[Claude Opus 4.5]] 之间的过渡版本，现为 Legacy 模型。后续版本 [[Claude Opus 4.5]] 将定价大幅下调至 $5/$25。对于新项目，建议使用 [[Claude Opus 4.8]]。

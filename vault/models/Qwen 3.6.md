# Qwen 3.6

[[Qwen 3.6]]（通义千问 3.6）是 [[Alibaba]]（阿里巴巴）发布的最新多模态大语言模型。Qwen3.6-27B 版本拥有 **27B（270亿）参数**，支持 Image-Text-to-Text 多模态任务，是 Qwen 系列的最新迭代。

## 核心参数

| 指标 | 数值 |
|------|------|
| 参数规模 | 27B (270亿，Qwen3.6-27B) |
| 类型 | Image-Text-to-Text 多模态 |
| 发布机构 | [[Alibaba]] |
| 平台 | Hugging Face |

## 技术特点

### 多模态能力
[[Qwen 3.6]] 支持 Image-Text-to-Text 任务，能够理解图像内容并生成文字描述、回答关于图像的问题、进行视觉推理等。

### 高效参数规模
27B 参数在多模态模型中属于高效规模，在保持强大能力的同时便于部署和推理。

### Qwen 系列演进
作为 Qwen 系列的最新版本，[[Qwen 3.6]] 在前代 [[Qwen 3]] 和 [[Qwen 2.5]] 的基础上，进一步提升了多模态理解和生成能力。

## 产品定位

[[Qwen 3.6]] 是 [[Alibaba]] 通义千问系列的最新力作，与 [[DeepSeek]]、[[Xiaomi]] 的 MiMo 系列等中国大模型竞争。Qwen 系列以开源策略和多模态能力著称，在全球开源社区有广泛采用。

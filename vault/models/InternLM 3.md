# InternLM 3

[[InternLM 3]] 是 [[上海AI实验室]]（Shanghai AI Lab）于 **2025年** 发布的大语言模型，是中国学术界在大模型领域的代表作。

## 核心参数

| 指标 | 数值 |
|------|------|
| 发布日期 | 2025年 |
| 参数量 | 8B（主要版本） |
| 上下文窗口 | 32K tokens |
| 最大输出 | 8,192 tokens |
| 架构 | [[Transformer]] |
| 开源许可 | Apache 2.0 |

## 架构与训练

InternLM 3 基于 [[Transformer]] 架构，由 [[上海AI实验室]] 联合多所高校研发。

训练特点：
- 大规模中英文混合预训练
- 高质量数据筛选和清洗
- [[RLHF]] 和 [[DPO]] 对齐优化
- 强调学术严谨性和可复现性
- 支持 [[Fine-tuning]] 和领域适配

## Benchmark 表现（InternLM3-8B）

| 基准测试 | 分数 | 备注 |
|----------|------|------|
| [[MMLU]] | 78.5% | 多领域知识 |
| [[HumanEval]] | 75.2% | 代码生成 |
| [[MATH]] | 68.3% | 数学推理 |
| 中文理解 | 优秀 | 学术中文 |

## 核心特点

### 学术严谨
InternLM 3 由学术机构开发，强调：
- 训练方法的可复现性
- 数据来源的透明性
- 评估方法的科学性
- 论文和技术报告的完整公开

### 开源生态
InternLM 系列是中文开源大模型的重要组成部分：
- 完整的模型权重开源
- 详细的训练文档
- 社区驱动的持续改进

### 工具链
[[上海AI实验室]] 提供了完整的工具链：
- InternLM-Train：训练框架
- InternLM-Evaluate：评估框架
- LMDeploy：推理部署工具
- XTuner：微调工具

## 中国 AI 学术力量

InternLM 3 代表了中国 AI 学术界在大模型领域的竞争力：
- [[上海AI实验室]] 是中国顶级的 AI 研究机构
- 联合了多所高校（复旦、交大等）的研发力量
- 推动了中国开源大模型生态的发展
- 与 [[Qwen 2.5]]、[[DeepSeek V3]] 共同构成了中国开源 AI 的三大力量

# GPT-4.1

[[GPT-4.1]] 是 [[OpenAI]] 于 **2025年4月14日** 发布的大语言模型，以超长上下文和编码能力为核心卖点，是 GPT-4o 的重要升级。

## 核心参数

| 指标 | 数值 |
|------|------|
| 发布日期 | 2025年4月14日 |
| 上下文窗口 | 1,048,576 tokens（1M） |
| 最大输出 | 32,768 tokens |
| 训练数据截止 | 2025年4月 |
| 架构 | [[Transformer]] |
| API 定价 | $2.00 / 1M input，$8.00 / 1M output |

## 架构与训练

GPT-4.1 采用改进的 [[Transformer]] 架构，针对长上下文处理进行了深度优化。通过改进的 [[Attention Mechanism]]，模型能够在 1M tokens 的上下文中保持高精度的信息检索和推理能力。

训练过程中大规模使用了合成数据和代码数据，显著提升了编码和指令遵循能力。模型经过 [[RLHF]] 和 [[DPO]] 的多轮对齐优化。

## Benchmark 表现

| 基准测试 | 分数 | 备注 |
|----------|------|------|
| [[SWE-bench]] | 54.6% | 软件工程任务（全栈） |

| [[IFEval]] | 87.4% | 指令遵循 |
| [[MATH]] | 78.3% | 数学推理 |
| 长上下文检索 | 98.2% | 1M token needle-in-haystack |

## 长上下文能力

GPT-4.1 最大的突破在于 1M token 的上下文窗口，与 [[Gemini 2.5 Pro]] 并列最长。在 "大海捞针" 测试中，即使在 1M token 的上下文末尾，检索准确率仍超过 98%。

这一能力使其特别适合：
- 大型代码库的全局理解和重构
- 长文档分析和摘要
- 多轮复杂对话中保持上下文一致性

## 编码能力

GPT-4.1 在 [[SWE-bench]] 上达到 54.6%，较 [[GPT-4o]] 提升约 21 个百分点，成为发布时编码能力最强的模型之一。在实际软件工程任务中，模型能够理解复杂的代码依赖关系，进行跨文件重构。

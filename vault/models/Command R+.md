# Command R+

[[Command R+]] 是 [[Cohere]] 于 **2024年4月** 发布的大语言模型，以 RAG（检索增强生成）能力为核心卖点，是企业级 AI 应用的重要选择。

## 核心参数

| 指标 | 数值 |
|------|------|
| 发布日期 | 2024年4月 |
| 参数量 | 104B |
| 上下文窗口 | 128K tokens |
| 最大输出 | 4,096 tokens |
| 架构 | [[Transformer]] |
| 许可 | CC-BY-NC（非商用） |

## 架构与训练

Command R+ 基于 [[Transformer]] 架构，针对企业级 RAG 场景进行了深度优化。

训练特点：
- 大规模预训练，注重知识密集型数据
- 针对 [[RAG]] 场景的专项优化训练
- [[RLHF]] 对齐优化
- 支持 10 种语言
- 优化的 [[Embeddings]] 和检索能力

## 核心能力

### RAG 优化
Command R+ 的最大特点是针对 [[RAG]] 场景的深度优化：
- 准确的引用生成：能够标注信息来源
- 长上下文检索：在 128K 上下文中准确检索相关信息
- 多文档综合：能够综合多个文档的信息进行回答
- 幻觉控制：通过 [[RAG]] 减少 [[Hallucination]]

### 企业级特性
- 工具使用：原生支持 [[Function Calling]]
- 多语言：支持 10 种主要语言
- 安全性：企业级内容安全过滤

### Cohere 生态
Command R+ 深度集成 Cohere 的企业 AI 平台：
- Cohere Embed：高质量 [[Embeddings]]
- Cohere Rerank：检索结果重排序
- Cohere Chat：企业对话 API

## 企业应用场景

- **文档问答**：基于企业知识库的智能问答
- **报告生成**：自动生成分析报告和摘要
- **客服系统**：基于产品文档的智能客服
- **合规检查**：文档合规性自动审查
- **知识管理**：企业知识库的智能检索和管理

## Cohere 公司定位

[[Cohere]] 定位为企业级 AI 解决方案提供商，Command R+ 是其核心产品。与 [[OpenAI]] 和 [[Anthropic]] 的通用模型不同，Cohere 专注于企业市场，提供从模型到平台的完整解决方案。

## 后续发展

Command R+ 被后续的 Command A（2025年）所接替，后者在性能和企业特性上进一步提升。

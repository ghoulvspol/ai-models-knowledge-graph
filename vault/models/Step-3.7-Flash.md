# Step-3.7-Flash

[[Step-3.7-Flash]] 是 [[StepFun AI]]（阶跃星辰）发布的最新大语言模型，拥有 **201B（2010亿）参数**。该模型支持 Image-Text-to-Text 多模态任务，是中国 AI 创业公司的最新力作。

## 核心参数

| 指标 | 数值 |
|------|------|
| 参数规模 | 201B (2010亿) |
| 类型 | Image-Text-to-Text 多模态 |
| 发布机构 | StepFun AI (阶跃星辰) |
| 平台 | Hugging Face |

## 技术特点

### 多模态能力
[[Step-3.7-Flash]] 支持 Image-Text-to-Text 任务，能够理解图像和文本的联合语义，进行视觉问答、图像描述等多模态交互。

### 大规模参数
201B 参数规模使模型在复杂推理和多模态理解上具备强大能力。

### "Flash" 优化
"Flash" 命名体现了模型在推理效率上的优化，在保持强大能力的同时注重响应速度。

## 公司背景

StepFun AI（阶跃星辰）是中国领先的 AI 创业公司，专注于大语言模型和多模态 AI 的研发。公司由姜大昕创立，在多模态理解和生成方面有深厚的技术积累。

## 产品定位

[[Step-3.7-Flash]] 是 StepFun AI 的最新旗舰模型，与 [[DeepSeek]]、[[Alibaba]] 的 Qwen、[[Xiaomi]] 的 MiMo 等中国大模型竞争。阶跃星辰以多模态能力见长，在图像理解和跨模态推理方面有独特优势。

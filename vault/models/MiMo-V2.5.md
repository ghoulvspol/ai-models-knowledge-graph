# MiMo-V2.5

[[MiMo-V2.5]] 是 [[Xiaomi]]（小米）发布的大语言模型，拥有 **311B（3110亿）参数**。该模型系列包含多个变体，覆盖文本生成、语音识别、音频处理和具身智能等多模态场景。

## 核心参数

| 指标 | 数值 |
|------|------|
| 参数规模 | 311B (3110亿) |
| 类型 | 文本生成 |
| 发布机构 | [[Xiaomi]] |
| 平台 | Hugging Face (XiaomiMiMo) |

## 模型变体

[[MiMo-V2.5]] 系列包含多个专业化变体：

| 变体 | 参数 | 能力 |
|------|------|------|
| MiMo-V2.5 (Base) | 311B | 文本生成 |
| MiMo-V2.5-ASR | 8B | 自动语音识别 |
| MiMo-V2.5-Audio | 7B | 音频理解与生成 |
| MiMo-V2.5-Embodied | 7B | 具身智能 |

### ASR 变体 (8B)
专注于自动语音识别的轻量级模型，适合端侧部署和实时语音转文字场景。

### Audio 变体 (7B)
音频理解与生成模型，支持语音对话、音频内容分析等多模态交互。

### Embodied 变体 (7B)
面向机器人和智能设备的具身智能模型，支持环境感知、动作规划和人机交互。

## 产品定位

[[MiMo-V2.5]] 是 [[Xiaomi]] MiMo 系列的多模态核心，通过多个专业化变体覆盖从文本到语音、从音频到具身智能的全场景 AI 需求。与旗舰 [[MiMo-V2.5-Pro]] (1T) 和高效变体 [[MiMo-V2-Flash]] (310B) 共同构成完整的产品矩阵。

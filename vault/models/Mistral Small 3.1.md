# Mistral Small 3.1

[[Mistral Small 3.1]] 是 [[Mistral AI]] 于 **2025年3月17日** 发布的轻量级大语言模型，仅有 24B 参数，但在多项基准上超越了数倍规模的模型。

## 核心参数

| 指标 | 数值 |
|------|------|
| 发布日期 | 2025年3月17日 |
| 参数量 | 24B |
| 上下文窗口 | 128K tokens |
| 最大输出 | 8,192 tokens |
| 架构 | [[Transformer]] |
| 开源许可 | Apache 2.0 |

## 架构与训练

Mistral Small 3.1 基于 [[Mistral AI]] 的 [[Transformer]] 架构，针对效率和性能进行了优化。

训练特点：
- 大规模多语言预训练
- [[RLHF]] 和 [[DPO]] 对齐优化
- 代码和数学数据的高权重训练
- 支持 [[Function Calling]] 和结构化输出
- [[Quantization]] 优化，支持端侧部署

## Benchmark 表现

| 基准测试 | 分数 | 备注 |
|----------|------|------|
| [[MMLU]] | 72.5% | 多领域知识 |
| [[HumanEval]] | 80.0% | 代码生成 |
| [[MATH]] | 58.7% | 数学推理 |
| [[IFEval]] | 75.2% | 指令遵循 |
| 多语言 | 优秀 | 欧洲语言突出 |

## 核心优势

### 效率
24B 参数经过 [[Quantization]] 后可以在消费级 GPU（如 RTX 4090 24GB）上运行，适合本地部署和边缘场景。

### 代码能力
[[HumanEval]] 80.0% 在 24B 级别模型中处于领先水平，适合编程辅助和代码生成。

### 多语言
继承 [[Mistral AI]] 的欧洲基因，在法语、德语、西班牙语等欧洲语言上表现优异。

### 开源
采用 Apache 2.0 许可，完全开放商用，支持 [[Fine-tuning]] 和二次开发。

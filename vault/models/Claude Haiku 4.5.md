# Claude Haiku 4.5

[[Claude Haiku 4.5]] 是 [[Anthropic]] 推出的轻量级模型，主打高速度、低成本，适合大规模部署和延迟敏感场景。

## 核心参数

| 指标 | 数值 |
|------|------|
| 发布日期 | 2025年初 |
| 上下文窗口 | 200K tokens |
| 最大输出 | 8,192 tokens |
| 架构 | [[Transformer]] |
| API 定价 | $0.80 / 1M input，$4.00 / 1M output |
| 首 token 延迟 | < 500ms |

## 设计理念

Claude Haiku 4.5 遵循"高效优先"的设计哲学：通过 [[Distillation]] 和 [[Quantization]] 技术，将大模型的知识压缩到更小的参数空间中，在保持 90% Sonnet 能力的同时，实现 3 倍以上的成本节省。

## 核心优势

### 速度
Haiku 4.5 的响应延迟显著低于 [[Claude Sonnet 4]] 和 [[Claude Opus 4]]，首 token 生成时间在 500ms 以内，适合实时交互场景。

### 成本
定价仅为 [[Claude Sonnet 4]] 的约 1/4，是 [[Anthropic]] 产品线中最经济的选择，适合大规模批处理和高并发场景。

### 能力密度
尽管是轻量模型，Haiku 4.5 在 90% 的实际任务中能够达到 [[Claude Sonnet 4]] 约 90% 的能力水平，性价比极高。

## 应用场景

- **客服对话**：低延迟、高并发的客户服务
- **内容分类**：大规模文本分类和情感分析
- **代码辅助**：日常编程、代码补全
- **数据提取**：结构化信息抽取
- **多 Agent 系统**：作为 [[AI Agent]] 系统中的工作者节点

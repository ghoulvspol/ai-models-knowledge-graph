# o4-mini

[[o4-mini]] 是 [[OpenAI]] 于 **2025年4月16日** 发布的轻量推理模型，与 [[o3]] 同期发布，定位为高性价比的推理解决方案。

## 核心参数

| 指标 | 数值 |
|------|------|
| 发布日期 | 2025年4月16日 |
| 上下文窗口 | 200K tokens |
| 最大输出 | 100,000 tokens |
| 架构 | [[Transformer]] + 推理链 |
| API 定价 | $1.10 / 1M input，$4.40 / 1M output |

## 设计理念

o4-mini 遵循 [[OpenAI]] 的"小模型推理"策略：通过 [[Distillation]] 和高效推理技术，将 [[o3]] 级别的推理能力压缩到更小、更便宜的模型中。

## Benchmark 表现

| 基准测试 | 分数 | 备注 |
|----------|------|------|
| [[MATH]] | 96.1% | 接近 o3 水平 |
| [[GPQA]] | 79.6% | 科学推理 |
| [[HumanEval]] | 94.8% | 代码生成 |
| [[SWE-bench]] | 68.2% | 软件工程 |
| [[MMLU]] | 89.5% | 多领域知识 |
| ARC-AGI | 63.8% | 抽象推理 |

## 与 o3 对比

| 指标 | o3 | o4-mini |
|------|-----|---------|
| ARC-AGI | 87.5% | 63.8% |
| MATH | 97.9% | 96.1% |
| Input 价格 | $10/1M | $1.10/1M |
| Output 价格 | $40/1M | $4.40/1M |
| 延迟 | 较高 | 较低 |
| 适用场景 | 最高精度 | 日常推理 |

o4-mini 的价格仅为 [[o3]] 的约 1/9，但在大多数任务上保持了 90% 以上的能力水平。

## 应用场景

- **日常编程辅助**：代码生成、调试、重构
- **数学和科学推理**：作业辅导、论文辅助
- **数据分析**：结构化数据的推理和总结
- **教育场景**：成本可控的 AI 教学助手

## 产品定位

o4-mini 是 [[OpenAI]] 推理产品线中的"性价比之王"，填补了 [[o1]]-mini 和 [[o3]] 之间的空白。其定价策略直接对标 [[Claude Haiku 4.5]] 和 [[Gemini 2.5 Flash]]，在推理密集型任务中具有竞争力。

## 技术特点

- 继承 [[o3]] 的推理链机制，但推理深度可控
- 支持结构化输出和 [[Function Calling]]
- 通过 [[Quantization]] 优化推理效率
- 适合高并发、成本敏感的生产环境

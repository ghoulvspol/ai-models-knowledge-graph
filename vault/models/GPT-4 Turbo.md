# GPT-4 Turbo

[[GPT-4 Turbo]] 是 [[OpenAI]] 于 **2023年11月6日** 在 DevDay 上发布的大语言模型，是 [[GPT-4]] 的重大升级版本，首次支持 128K 上下文和多模态输入。

## 核心参数

| 指标 | 数值 |
|------|------|
| 发布日期 | 2023年11月6日 |
| 上下文窗口 | 128K tokens |
| 最大输出 | 4,096 tokens |
| 训练数据截止 | 2023年4月 |
| 架构 | [[Transformer]] |
| API 定价 | $10 / 1M input，$30 / 1M output |
| 模型标识 | gpt-4-turbo-preview / gpt-4-1106-preview |

## 架构与训练

GPT-4 Turbo 基于 [[GPT-4]] 的 [[Transformer]] 架构，进行了多项关键升级：

改进内容：
- 上下文窗口从 8K/32K 扩展到 128K
- 首次支持图像输入（多模态）
- 支持 [[Function Calling]] 的改进版本
- 支持 JSON 模式（结构化输出）
- 知识更新至 2023 年 4 月
- 价格大幅下降（相比 GPT-4）

## 核心改进

### 128K 上下文
GPT-4 Turbo 是首个支持 128K token 上下文的 GPT 系列模型，能够处理约 300 页文本，大幅扩展了应用场景。

### 多模态输入
首次在 GPT-4 系列中支持图像输入，用户可以通过 API 发送图片让模型理解。

### Function Calling
改进的 [[Function Calling]] 能力，支持并行函数调用、JSON 模式输出，为 [[AI Agent]] 开发奠定了基础。

### 价格下降
| 模型 | Input 价格 | Output 价格 |
|------|-----------|-------------|
| GPT-4 | $30 / 1M | $60 / 1M |
| GPT-4 Turbo | $10 / 1M | $30 / 1M |

价格下降约 3 倍，推动了 GPT-4 级别能力的大规模应用。

## 历史地位

GPT-4 Turbo 是 GPT-4 系列的"完全体"版本，将 128K 上下文、多模态、Function Calling 等能力集于一体，奠定了现代 LLM API 的标准范式。

其后继者 [[GPT-4o]] 进一步将价格降低 50%，并引入原生多模态，但 GPT-4 Turbo 在 2023-2024 年间定义了 AI 应用开发的标准接口。

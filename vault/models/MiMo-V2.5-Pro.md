# MiMo-V2.5-Pro

[[MiMo-V2.5-Pro]] 是 [[Xiaomi]]（小米）发布的旗舰大语言模型，拥有 **1万亿（1T）参数**，是小米 MiMo 系列中规模最大、能力最强的模型。该模型专注于文本生成和指令微调（instruction-tuned）。

## 核心参数

| 指标 | 数值 |
|------|------|
| 参数规模 | 1T (1万亿) |
| 类型 | 文本生成、指令微调 |
| 发布机构 | [[Xiaomi]] |
| 平台 | Hugging Face (XiaomiMiMo) |

## 技术特点

### 超大规模参数
作为小米首个万亿参数模型，[[MiMo-V2.5-Pro]] 代表了小米在大模型领域的重大突破。1T 参数规模使其在复杂推理、多语言理解和代码生成等任务上具备强大能力。

### 指令微调
模型经过深度指令微调（instruction-tuned），能够准确理解和执行用户指令，在对话、问答、摘要等场景中表现出色。

### 文本生成
专注于文本生成任务，支持多种语言和风格的高质量文本输出。

## MiMo 系列

小米的 MiMo 大模型系列形成了完整的产品矩阵：

| 模型 | 参数规模 | 类型 |
|------|---------|------|
| [[MiMo-V2.5-Pro]] | 1T | 文本生成（旗舰） |
| [[MiMo-V2.5]] | 311B | 文本生成 + 多模态变体 |
| [[MiMo-V2-Flash]] | 310B | 高效推理变体 |

### 多模态变体（MiMo-V2.5 系列）
- **ASR (8B)**：自动语音识别
- **Audio (7B)**：音频理解与生成
- **Embodied (7B)**：具身智能

## 产品定位

[[MiMo-V2.5-Pro]] 是 [[Xiaomi]] AI 战略的核心，与 [[DeepSeek]]、[[Alibaba]] 的 Qwen 系列、[[Baidu]] 的文心系列等中国大模型展开竞争。小米的独特优势在于其庞大的 IoT 设备生态，为模型提供了丰富的应用场景。

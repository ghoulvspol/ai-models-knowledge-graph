# Claude Mythos Preview

[[Claude Mythos Preview]] 是 [[Anthropic]] 推出的专用网络安全模型，属于 **Project Glasswing** 计划的一部分。该模型专为防御性网络安全工作流设计，目前仅限受邀用户使用（Invitation-only）。

## 核心参数

| 指标 | 数值 |
|------|------|
| 类型 | 网络安全专用模型 |
| 项目 | Project Glasswing |
| 访问方式 | 仅限受邀 (Invitation-only) |
| 状态 | Research Preview |
| 发布机构 | [[Anthropic]] |

## 核心能力

### 防御性网络安全
[[Claude Mythos Preview]] 专注于防御性网络安全工作流，包括：
- 威胁检测与分析
- 漏洞评估与修复建议
- 安全日志分析与异常检测
- 安全策略制定与审查
- 事件响应辅助

### Research Preview
作为研究预览模型，[[Claude Mythos Preview]] 代表了 [[Anthropic]] 在 AI 安全应用方面的前沿探索。模型能力仍在持续迭代和优化中。

## Project Glasswing

Project Glasswing 是 [[Anthropic]] 的网络安全 AI 计划，旨在将 AI 能力应用于防御性安全场景。[[Claude Mythos Preview]] 是该计划的首个公开模型。

## 访问方式

该模型目前仅限受邀使用，面向安全研究人员和企业安全团队开放。感兴趣的用户需要通过 [[Anthropic]] 官方渠道申请访问权限。

## 产品定位

[[Claude Mythos Preview]] 代表了 AI 在专业垂直领域应用的新方向。与 [[Anthropic]] 的通用模型（如 [[Claude Opus 4.8]]、[[Claude Sonnet 4.6]]）不同，它专注于网络安全这一特定领域，提供更精准和专业的安全分析能力。

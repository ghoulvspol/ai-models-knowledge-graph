# Llama 4 Maverick

[[Llama 4 Maverick]] 是 [[Meta AI]] 于 **2025年4月5日** 发布的旗舰开源模型，采用大规模 [[MoE]] 架构，400B 总参数，与 [[Llama 4 Scout]] 同期发布。

## 核心参数

| 指标 | 数值 |
|------|------|
| 发布日期 | 2025年4月5日 |
| 总参数 | 400B |
| 激活参数 | 17B（每次推理） |
| 上下文窗口 | 1,000,000 tokens（1M） |
| 最大输出 | 32,768 tokens |
| 架构 | [[Transformer]]，[[MoE]]（128 专家） |
| 开源许可 | Llama 4 Community License |

## 架构与训练

Llama 4 Maverick 采用大规模 [[MoE]] 架构：

| 组件 | 数值 |
|------|------|
| 总参数量 | 400B |
| 专家数量 | 128 |
| 每次激活专家 | 1 |
| 激活参数 | 17B |
| 层数 | 48 |
| 注意力头数 | 48 |
| 隐藏维度 | 6144 |

128 专家的 [[MoE]] 设计使模型拥有极大的知识容量，但每次推理仅激活 17B 参数，推理效率极高。

训练方法：
- 超大规模预训练，覆盖 200+ 语言
- [[MoE Training]] 的专家负载均衡优化
- [[RLHF]] 和 [[DPO]] 多阶段对齐
- 合成数据增强训练

## 核心能力

### 知识密度
128 专家的设计使模型在各领域都拥有专门的"专家网络"，在知识密集型任务上表现优异。[[MMLU]] 87.5% 的分数在开源模型中处于领先地位。

### 高效推理
尽管拥有 400B 总参数，每次推理仅需 17B 活跃参数，推理成本与 17B 模型相当。这使得 Maverick 在性价比上远超传统的 dense 模型。

### 多语言能力
训练数据覆盖 200+ 语言，在多语言翻译、理解和生成任务上具有显著优势。

## MoE 效率分析

| 指标 | Maverick | Llama 3.1 405B |
|------|----------|----------------|
| 总参数 | 400B | 405B |
| 推理参数 | 17B | 405B |
| 推理成本比 | ~4% | 100% |
| MMLU | 87.5% | 88.6% |

Maverick 以不到 1/10 的推理成本达到了接近 Llama 3.1 405B 的性能水平。

## 开源意义

Llama 4 Maverick 证明了 [[MoE]] 架构在开源大模型中的可行性，推动了开源社区从 dense 模型向 MoE 模型的转型。与 [[DeepSeek V3]] 共同引领了 MoE 开源浪潮。

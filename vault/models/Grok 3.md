# Grok 3

[[Grok 3]] 是 [[xAI]] 于 **2025年2月17日** 发布的大语言模型，在 10 万张 [[NVIDIA]] H100 GPU 的集群上训练，是当时最大规模的 AI 训练项目之一。

## 核心参数

| 指标 | 数值 |
|------|------|
| 发布日期 | 2025年2月17日 |
| 参数量 | 未公开（估算 > 1T） |
| 上下文窗口 | 128K tokens |
| 最大输出 | 16,384 tokens |
| 架构 | [[Transformer]]，推测采用 [[MoE]] |
| 训练集群 | 100,000 H100 GPU |
| 训练时间 | 约 3 个月 |

## 架构与训练

Grok 3 在 [[xAI]] 自建的 Memphis 超级计算机上训练，该集群拥有 100,000 张 [[NVIDIA]] H100 GPU，是当时全球最大的 AI 训练集群之一。

训练特点：
- 超大规模预训练，数据量未公开但估算超过 20T tokens
- [[RLHF]] 和人类反馈优化
- 实时数据接入（通过 X/Twitter 平台）
- 支持深度推理模式（"Think"模式）

## 核心能力

### 推理能力
Grok 3 的"Think"模式允许模型进行深度推理，在数学竞赛（AIME 2025）上达到 93.3%，展示了强大的数学推理能力。

### 实时信息
通过与 X/Twitter 平台的集成，Grok 3 能够访问实时信息和社交动态，这是其他模型不具备的独特优势。

### 规模效应
10 万 H100 的训练规模验证了 [[Scaling Laws]] 在超大规模下的有效性，展示了计算量与模型能力的正相关关系。

# Qwen 3

[[Qwen 3]] 是 [[阿里巴巴]] 通义千问团队于 **2025年4月29日** 发布的多尺寸大语言模型系列，覆盖从 0.6B 到 235B 的完整产品线，支持 MoE 和 Dense 两种架构。

## 架构与训练

Qwen 3 系列采用两种架构：

### Dense 模型
- 标准 [[Transformer]] 架构
- 从 0.6B 到 32B 的完整尺寸覆盖
- 适合边缘设备和资源受限场景

### MoE 模型
- [[MoE]]（Mixture of Experts）架构
- Qwen3-30B-A3B：30B 总参数，3B 激活参数
- Qwen3-235B-A22B：235B 总参数，22B 激活参数
- 适合大规模部署和高性能场景

训练特点：
- 超大规模中英文混合预训练
- 支持"思考模式"切换（深度推理/快速响应）
- [[RLHF]] 和 [[DPO]] 多阶段对齐
- [[MoE Training]] 专家路由优化

## 核心优势

### 中文能力
作为中国团队开发的模型，Qwen 3 在中文理解和生成任务上处于领先地位，包括中文古文、方言、专业术语等。

### 全尺寸覆盖
从手机端（0.6B）到云端（235B），Qwen 3 提供了业界最完整的尺寸矩阵，满足从边缘到云端的全场景需求。

### 开源
所有模型均开源，采用 Apache 2.0 许可，支持商业使用和 [[Fine-tuning]]。

## 开源生态

Qwen 3 是中国开源大模型的重要力量，与 [[DeepSeek]] 共同推动了中国 AI 开源生态的繁荣。模型在 Hugging Face 上的下载量位居前列。

## 应用场景

- 企业级中文 AI 应用
- 边缘设备部署（小尺寸模型）
- 大规模 API 服务（MoE 模型）
- 领域 [[Fine-tuning]] 基座
- 多语言翻译和本地化

# Yi-Lightning

[[Yi-Lightning]] 是 [[零一万物]]（01.AI）于 **2024年** 发布的大语言模型，以极致的推理速度为核心卖点，是速度优先场景的理想选择。

## 核心参数

| 指标 | 数值 |
|------|------|
| 发布日期 | 2024年 |
| 参数量 | 未公开 |
| 上下文窗口 | 16K tokens |
| 最大输出 | 4,096 tokens |
| 架构 | [[Transformer]] |
| 特点 | 极致推理速度 |

## 架构与训练

Yi-Lightning 由 [[零一万物]]（由 [[李开复]] 创立）开发，专注于推理速度优化。

训练特点：
- 大规模中英文预训练
- 针对推理速度的架构优化
- [[Quantization]] 和推理加速技术
- [[RLHF]] 对齐优化

## Benchmark 表现

| 基准测试 | 分数 | 备注 |
|----------|------|------|
| [[MMLU]] | 约 80% | 多领域知识 |
| [[Arena]] | Top 10（速度类） | 人类偏好 |
| 推理速度 | SOTA | 首 token < 200ms |

## 核心优势

### 极致速度
Yi-Lightning 的核心卖点是推理速度：
- 首 token 延迟 < 200ms
- 吞吐量远超同规模模型
- 适合实时交互和高并发场景

### 中文能力
作为中国团队开发的模型，Yi-Lightning 在中文理解和生成上具有优势。

## 零一万物公司

[[零一万物]]（01.AI）由 [[李开复]] 于 2023 年创立，定位为"AI 2.0 时代的效率革命者"。公司专注于：
- 高效推理技术
- 中文大模型
- 企业级 AI 解决方案

Yi 系列模型包括 Yi、Yi-1.5、Yi-Lightning 等多个版本。

## 局限性

- 参数量和架构细节未公开
- 上下文窗口较小（16K）
- 基准分数在头部模型中不占优势
- 主要面向中国市场，国际影响力有限

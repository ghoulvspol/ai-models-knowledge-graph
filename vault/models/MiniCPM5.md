# MiniCPM5

[[MiniCPM5]] 是 [[OpenBMB]]（清华系开源组织）发布的最新小型语言模型。MiniCPM5-1B 版本仅拥有 **1B（10亿）参数**，专注于高效文本生成，是小参数量模型领域的最新突破。

## 核心参数

| 指标 | 数值 |
|------|------|
| 参数规模 | 1B (10亿，MiniCPM5-1B) |
| 类型 | 文本生成 |
| 发布机构 | OpenBMB |
| 平台 | Hugging Face |

## 技术特点

### 极致效率
[[MiniCPM5]] 在仅 1B 参数的规模下实现了令人印象深刻的文本生成能力，体现了小模型高效化的技术趋势。

### 端侧部署友好
1B 参数规模使得 [[MiniCPM5]] 可以在消费级 GPU、甚至高端移动设备上运行，适合端侧 AI 场景。

### MiniCPM 系列演进
MiniCPM 系列以"小而精"著称，每一代都在更小的参数规模下实现更强的能力。[[MiniCPM5]] 是该系列的最新迭代。

## 产品定位

[[MiniCPM5]] 面向需要高效推理和端侧部署的场景，与 [[Microsoft]] 的 Phi 系列等小型模型竞争。在教育、移动应用、IoT 设备等资源受限的场景中有广泛应用前景。

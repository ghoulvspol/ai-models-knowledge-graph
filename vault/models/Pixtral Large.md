# Pixtral Large

[[Pixtral Large]] 是 [[Mistral AI]] 于 **2024年11月** 发布的多模态大语言模型，是 Mistral 首个大规模视觉语言模型。

## 核心参数

| 指标 | 数值 |
|------|------|
| 发布日期 | 2024年11月 |
| 参数量 | 124B（语言模型）+ 400M（视觉编码器） |
| 上下文窗口 | 128K tokens |
| 最大输出 | 8,192 tokens |
| 架构 | [[Transformer]] + 视觉编码器 |
| 许可 | Mistral Research License |

## 架构与训练

Pixtral Large 采用多模态架构：

| 组件 | 参数 | 功能 |
|------|------|------|
| 语言模型 | 124B | 基于 [[Mistral Large 2]] |
| 视觉编码器 | 400M | 图像理解 |
| 投影层 | - | 视觉-语言对齐 |

训练特点：
- 基于 [[Mistral Large 2]] 的语言能力
- 大规模图文对数据训练
- 视觉指令微调
- 支持多图输入
- [[RLHF]] 多模态对齐

## 核心能力

### 视觉理解
Pixtral Large 能够理解：
- 自然图像：物体识别、场景理解
- 文档图像：OCR、表格提取
- 图表图像：数据图表分析
- 多图推理：跨图像的逻辑推理

### 多语言视觉
继承 [[Mistral Large 2]] 的 80+ 语言支持，在多语言视觉任务上表现优异。

### 长文档理解
128K 上下文窗口支持长文档的视觉理解，适合处理包含大量图表的报告和论文。

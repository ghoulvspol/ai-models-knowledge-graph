# Claude Sonnet 4.5

[[Claude Sonnet 4.5]] 是 [[Anthropic]] 发布的中高端模型，API ID 为 claude-sonnet-4-5-20250929。作为 [[Claude Sonnet 4]] 的后继者，它在推理能力上有所提升，同时保持 Sonnet 系列的速度优势。现已标记为 Legacy 模型。

## 核心参数

| 指标 | 数值 |
|------|------|
| API ID | claude-sonnet-4-5-20250929 |
| 上下文窗口 | 200k tokens |
| 扩展思考 | 是 |
| 状态 | Legacy |
| API 定价 | $3 / 1M input，$15 / 1M output |

## 核心特性

### 扩展思考
[[Claude Sonnet 4.5]] 支持扩展思考（Extended Thinking）模式，在数学推理、逻辑分析等复杂任务上可显著提升准确率。

### 速度与智能平衡
继承 Sonnet 系列的核心定位，在保持快速响应的同时提供更强的推理能力。

## 产品定位

[[Claude Sonnet 4.5]] 已被 [[Claude Sonnet 4.6]] 取代，后者将上下文窗口扩展至 1M tokens 并引入自适应思考。对于新项目，建议使用 [[Claude Sonnet 4.6]]。

# DBRX

[[DBRX]] 是 [[Databricks]] 于 **2024年3月27日** 发布的开源大语言模型，采用 [[MoE]] 架构，是 Databricks 首个自研的大规模语言模型。

## 核心参数

| 指标 | 数值 |
|------|------|
| 发布日期 | 2024年3月27日 |
| 总参数 | 132B |
| 激活参数 | 36B（每次推理） |
| 上下文窗口 | 32K tokens |
| 最大输出 | 4,096 tokens |
| 架构 | [[Transformer]]，[[MoE]]（16 专家） |
| 训练成本 | 约 $10M |
| 开源许可 | Databricks Open Model License |

## 架构与训练

DBRX 采用 [[MoE]]（Mixture of Experts）架构：

| 组件 | 数值 |
|------|------|
| 总参数量 | 132B |
| 专家数量 | 16 |
| 每次激活专家 | 4 |
| 激活参数 | 36B |
| 层数 | 40 |
| 注意力头数 | 48 |
| 隐藏维度 | 6144 |

训练特点：
- 12T token 预训练数据
- 基于 [[Databricks]] 自有的数据处理平台
- [[MoE Training]] 的专家路由优化
- 训练成本约 $10M

## Benchmark 表现

| 基准测试 | DBRX | [[Llama 3.1 70B]] | [[Mistral Large 2]] |
|----------|------|------------------|-------------------|
| [[MMLU]] | 73.7% | 86.0% | 84.0% |
| [[HumanEval]] | 70.1% | 80.5% | 92.0% |
| [[MATH]] | 48.1% | 68.0% | 69.1% |
| 语言理解 | 良好 | 优秀 | 优秀 |

DBRX 的基准分数在发布时不占优势，但其 [[MoE]] 架构带来了推理效率上的优势。

## 核心特点

### MoE 效率
DBRX 的 [[MoE]] 设计使其在推理时仅激活 36B 参数（总参数的 27%），推理效率远高于同等规模的 Dense 模型。

### Databricks 生态
DBRX 深度集成 [[Databricks]] 数据平台：
- 原生支持 Delta Lake 数据
- 与 MLflow 集成
- 支持 Unity Catalog 数据治理
- 企业级部署和监控

### 开源
DBRX 采用 Databricks Open Model License，支持商用和 [[Fine-tuning]]。

## 行业意义

DBRX 是 [[Databricks]] 进入大模型领域的标志性产品，虽然在基准分数上不占优势，但证明了：
- 数据平台公司可以自研大模型
- [[MoE]] 架构在开源模型中的可行性
- 企业级 AI 需要与数据平台深度集成

## 局限性

- 32K 上下文窗口在当时已显不足
- 基准分数落后于同期竞品
- 132B 总参数在后续 [[MoE]] 模型中偏小

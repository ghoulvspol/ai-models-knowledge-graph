# Gemini 1.5 Pro

[[Gemini 1.5 Pro]] 是 [[Google DeepMind]] 于 **2024年2月15日** 发布的大语言模型，首次将上下文窗口扩展到 1M tokens，开创了超长上下文的新时代。

## 核心参数

| 指标 | 数值 |
|------|------|
| 发布日期 | 2024年2月15日（预览），2024年5月 GA |
| 上下文窗口 | 1,048,576 tokens（1M） |
| 最大输出 | 8,192 tokens |
| 架构 | [[Transformer]]，[[MoE]] |
| API 定价 | $3.50 / 1M input，$10.50 / 1M output |

## 架构与训练

Gemini 1.5 Pro 采用 [[MoE]]（Mixture of Experts）架构，是 Gemini 系列中首个采用 MoE 设计的模型。

核心创新：
- **1M token 上下文**：业界首个支持百万级上下文的商用模型
- [[MoE]] 架构：高效处理长上下文
- 原生多模态：文本、图像、音频、视频
- 改进的 [[Attention Mechanism]]：高效处理超长序列

## Benchmark 表现

| 基准测试 | 分数 | 备注 |
|----------|------|------|
| [[MMLU]] | 85.9% | 多领域知识 |
| [[HumanEval]] | 84.1% | 代码生成 |
| [[MATH]] | 67.7% | 数学推理 |
| [[GPQA]] | 58.5% | 研究生级问答 |
| 长上下文检索 | 99.7% | 1M token needle-in-haystack |

## 核心突破

### 1M 上下文
Gemini 1.5 Pro 是首个支持 1M token 上下文的商用模型，能够处理：
- 完整的代码仓库
- 长篇小说或学术论文集
- 1 小时的视频
- 11 小时的音频

在"大海捞针"测试中，即使在 1M token 的上下文末尾，信息检索准确率仍达到 99.7%。

### 原生多模态
支持文本、图像、音频、视频的统一处理，无需额外的模态转换管道。

### MoE 效率
通过 [[MoE]] 架构，模型在处理 1M token 上下文时仍保持合理的推理成本和延迟。

## 行业影响

Gemini 1.5 Pro 的 1M 上下文窗口引发了行业的"上下文竞赛"：
- 迫使 [[OpenAI]] 将 [[GPT-4.1]] 扩展到 1M
- 迫使 [[Anthropic]] 强化长上下文能力
- 推动了 [[RAG]] 之外的长文档处理方案
- 开创了"上下文即服务"的新范式

## 后续发展

Gemini 1.5 Pro 的技术积累直接影响了 [[Gemini 2.5 Pro]] 的设计，后者继承了 1M 上下文能力并加入了思维模式。

# Llama 3.1 405B

[[Llama 3.1 405B]] 是 [[Meta AI]] 于 **2024年7月23日** 发布的开源大语言模型，是当时最大的开源密集模型，证明了开源模型可以与闭源旗舰竞争。

## 核心参数

| 指标 | 数值 |
|------|------|
| 发布日期 | 2024年7月23日 |
| 参数量 | 405B |
| 上下文窗口 | 128K tokens |
| 最大输出 | 16,384 tokens |
| 架构 | [[Transformer]]，Dense |
| 训练集群 | 16,384 H100 GPU |
| 训练时间 | 约 54 天 |
| 训练 token | 15T+ |
| 开源许可 | Llama 3.1 Community License |

## 架构与训练

Llama 3.1 405B 是标准的 Dense [[Transformer]] 模型，不采用 [[MoE]] 架构，所有 405B 参数在每次推理时全部激活。

| 组件 | 数值 |
|------|------|
| 参数量 | 405B |
| 层数 | 126 |
| 注意力头数 | 128 |
| KV 头数 | 8（GQA） |
| 隐藏维度 | 16384 |
| 词表大小 | 128,256 |

训练细节：
- 16,384 张 [[NVIDIA]] H100 GPU
- 训练时间约 54 天
- 训练数据超过 15T tokens
- 多语言数据，支持 8 种语言
- [[RLHF]] 对齐优化

Llama 3.1 405B 在 [[MMLU]] 上与 [[GPT-4o]] 和 [[Claude 3.5 Sonnet]] 持平，证明了开源模型的竞争力。

## 核心突破

### 开源里程碑
Llama 3.1 405B 是首个在主流基准上与 GPT-4 级别模型持平的开源模型，打破了"开源模型必然落后"的认知。

### 128K 上下文
首次在 Llama 系列中支持 128K token 上下文，与 [[GPT-4 Turbo]] 持平。

### 蒸馏生态
Meta 同时发布了 8B 和 70B 版本，通过 [[Distillation]] 从 405B 中学习，形成了完整的尺寸矩阵。

## 与 MoE 模型对比

| 模型 | 总参数 | 推理参数 | MMLU | 开源 |
|------|--------|----------|------|------|
| Llama 3.1 405B | 405B | 405B | 88.6% | 是 |
| [[DeepSeek V3]] | 671B | 37B | 88.5% | 是 |
| [[Llama 4 Maverick]] | 400B | 17B | 87.5% | 是 |

Llama 3.1 405B 作为 Dense 模型，推理成本远高于 MoE 模型，但其简洁的架构便于理解和优化。

## 开源影响

Llama 3.1 405B 推动了开源大模型生态的爆发：
- 被广泛用于 [[Fine-tuning]] 和领域适配
- 推动了 [[Quantization]] 技术的发展（在消费级硬件上运行）
- 成为开源社区的基准模型
- 影响了 [[DeepSeek V3]]、[[Qwen 3]] 等后续开源模型的设计

## 局限性

- Dense 架构导致推理成本高（所有参数激活）
- 128K 上下文在当时领先，但已被 [[Gemini 1.5 Pro]]（1M）超越
- 需要大量 GPU 内存进行推理

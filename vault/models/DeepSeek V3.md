# DeepSeek V3

[[DeepSeek V3]] 是 [[DeepSeek]] 于 **2024年12月26日** 发布的开源大语言模型，以 671B 总参数的 [[MoE]] 架构和极低的训练成本震惊业界。

## 核心参数

| 指标 | 数值 |
|------|------|
| 发布日期 | 2024年12月26日 |
| 总参数 | 671B |
| 激活参数 | 37B（每次推理） |
| 上下文窗口 | 128K tokens |
| 最大输出 | 16,384 tokens |
| 架构 | [[Transformer]]，[[MoE]]（256 专家 + 1 共享专家） |
| 训练成本 | 约 $5.576M（2048 H800 GPU） |
| 开源许可 | DeepSeek License |

## 架构与训练

DeepSeek V3 采用创新的 [[MoE]] 架构：

| 组件 | 数值 |
|------|------|
| 总参数量 | 671B |
| 路由专家数量 | 256 |
| 共享专家数量 | 1 |
| 每次激活路由专家 | 8 |
| 激活参数 | 37B |
| 层数 | 61 |
| 注意力头数 | 128 |
| KV 头数 | 128 |

核心创新：
- **Multi-head Latent Attention (MLA)**：压缩 KV 缓存，降低推理内存
- **DeepSeekMoE**：路由专家 + 共享专家的混合设计
- **辅助损失无关的负载均衡**：无需额外损失函数即可实现专家均衡
- **FP8 混合精度训练**：降低计算和内存成本
- **DualPipe 流水线并行**：最小化流水线气泡

## 训练成本革命

DeepSeek V3 最令人震惊的是其训练成本：

| 模型 | 训练 GPU | 训练时间 | 估算成本 |
|------|----------|----------|----------|
| DeepSeek V3 | 2048 H800 | ~2个月 | **$5.576M** |
| [[Llama 3.1 405B]] | 16384 H100 | ~54天 | ~$60M |
| [[GPT-4]]（估算） | ~25000 A100 | ~100天 | ~$100M+ |

DeepSeek V3 以约 1/10 的成本达到了与 [[GPT-4]] 相当的性能水平，这一成就挑战了"训练大模型必须烧钱"的行业共识。

## 核心技术突破

### Multi-head Latent Attention (MLA)
将 KV 缓存压缩到极小空间，大幅降低推理时的内存占用和计算成本。

### DeepSeekMoE
创新的 [[MoE]] 变体，引入共享专家处理通用知识，路由专家处理专业知识，提高了专家利用率。

### FP8 训练
率先在 671B 规模上成功应用 FP8 混合精度训练，将训练效率提升约 40%。

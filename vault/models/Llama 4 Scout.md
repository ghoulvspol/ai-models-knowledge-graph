# Llama 4 Scout

[[Llama 4 Scout]] 是 [[Meta AI]] 于 **2025年4月5日** 发布的开源大语言模型，采用 [[MoE]] 架构，以 10M token 的超长上下文窗口和开源策略为核心亮点。

## 核心参数

| 指标 | 数值 |
|------|------|
| 发布日期 | 2025年4月5日 |
| 总参数 | 109B |
| 激活参数 | 17B（每次推理） |
| 上下文窗口 | 10,000,000 tokens（10M） |
| 最大输出 | 32,768 tokens |
| 架构 | [[Transformer]]，[[MoE]]（16 专家） |
| 开源许可 | Llama 4 Community License |

## 架构与训练

Llama 4 Scout 采用 [[MoE]]（Mixture of Experts）架构：

| 组件 | 数值 |
|------|------|
| 总参数量 | 109B |
| 专家数量 | 16 |
| 每次激活专家 | 1 |
| 激活参数 | 17B |
| 层数 | 48 |
| 注意力头数 | 32 |
| 隐藏维度 | 5120 |

[[MoE]] 架构的优势在于：总参数量大但每次推理只激活一小部分，实现了"大模型能力、小模型成本"。

训练方法：
- 超大规模预训练，多语言数据
- 改进的 [[Attention Mechanism]] 支持超长上下文
- [[RLHF]] 对齐优化
- [[MoE Training]] 专家路由优化

## 核心能力

### 10M 上下文
Llama 4 Scout 拥有业界最长的 10M token 上下文窗口，是 [[Gemini 2.5 Pro]]（1M）的 10 倍，[[GPT-4.1]]（1M）的 10 倍。这一能力使其能够处理：
- 完整的大型代码仓库
- 数千页的文档集
- 长视频的逐帧理解

### 开源优势
作为开源模型，Llama 4 Scout 可以：
- 本地部署，数据不出境
- 自由微调，适配特定领域
- 通过 [[Quantization]] 在消费级硬件运行
- 无 API 调用费用（自建推理）

## 开源生态

Llama 4 Scout 延续了 [[Meta AI]] 的开源策略，推动了开源大模型生态的发展。与 [[DeepSeek V3]]、[[Qwen 3]] 等开源模型共同构成了开源 AI 的核心力量。

## 应用场景

- 企业私有化部署
- 长文档分析和知识管理
- 多语言翻译和本地化
- 代码仓库级别的理解和重构
- 作为 [[Fine-tuning]] 基座模型

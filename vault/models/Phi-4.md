# Phi-4

[[Phi-4]] 是 [[Microsoft]] 于 **2024年12月12日** 发布的小参数大语言模型，仅有 14B 参数，但在多项基准上超越了数倍规模的模型，树立了小模型的新标杆。

## 核心参数

| 指标 | 数值 |
|------|------|
| 发布日期 | 2024年12月12日 |
| 参数量 | 14B |
| 上下文窗口 | 16K tokens |
| 最大输出 | 8,192 tokens |
| 架构 | [[Transformer]] |
| 训练数据 | 合成数据为主 |
| 开源许可 | MIT License |

## 架构与训练

Phi-4 采用标准 [[Transformer]] 架构，核心创新在于训练数据策略：

训练特点：
- **合成数据为主**：大量使用 GPT-4 级别模型生成的高质量合成数据
- **数据质量 > 数据数量**：精心筛选和过滤的训练数据
- **多阶段训练**：预训练 → 指令微调 → [[RLHF]]
- **推理优化**：通过 [[Quantization]] 支持端侧部署

## Benchmark 表现

| 基准测试 | Phi-4 (14B) | [[GPT-4o-mini]] | [[Llama 3.1 8B]] | 备注 |
|----------|-------------|----------------|------------------|------|
| [[MMLU]] | 84.8% | 82.0% | 73.0% | 多领域知识 |
| [[GPQA]] | 56.1% | 40.2% | 32.8% | 研究生级问答 |
| [[MATH]] | 80.4% | 70.2% | 51.9% | 数学推理 |
| [[HumanEval]] | 82.6% | 87.2% | 72.0% | 代码生成 |
| [[MUSR]] | 72.0% | 63.2% | 48.5% | 多步推理 |

Phi-4 在 14B 参数下，[[GPQA]] 和 [[MATH]] 上大幅超越了 [[GPT-4o-mini]] 和 [[Llama 3.1 8B]]。

## 核心突破

### 合成数据训练
Phi-4 证明了合成数据可以成为高质量训练的核心来源。通过精心设计的合成数据生成管道，模型在数学和科学推理上达到了远超其规模的水平。

### 数据质量革命
Phi-4 的成功挑战了"更多数据 = 更好模型"的传统认知，证明了数据质量的重要性可以超越数据数量。

### 端侧部署
14B 参数经过 [[Quantization]] 后可以在消费级 GPU（如 RTX 4090）上运行，推动了 AI 的端侧部署。

## 行业影响

Phi-4 的发布推动了"小模型运动"：
- 证明了数据质量比模型规模更重要
- 推动了合成数据在训练中的广泛应用
- 促进了端侧 AI 部署的发展
- 影响了 [[Distillation]] 技术的研究方向

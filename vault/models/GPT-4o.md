# GPT-4o

[[GPT-4o]] 是 [[OpenAI]] 于 **2024年5月13日** 发布的多模态旗舰模型，"o" 代表 "omni"（全能），是首个原生支持文本、图像、音频输入输出的统一模型。

## 核心参数

| 指标 | 数值 |
|------|------|
| 发布日期 | 2024年5月13日 |
| 上下文窗口 | 128K tokens |
| 最大输出 | 16,384 tokens |
| 训练数据截止 | 2023年10月 |
| 架构 | [[Transformer]]，多模态原生 |
| API 定价 | $2.50 / 1M input，$10.00 / 1M output |

## 架构与训练

GPT-4o 采用端到端多模态架构，文本、音频、图像共享同一神经网络，无需模态间转换管道。相比前代 [[GPT-4 Turbo]] 的语音流水线（ASR → LLM → TTS），GPT-4o 原生处理音频，延迟降至约 320ms，接近人类对话响应速度。

模型基于 [[Transformer]] 架构，结合 [[Scaling Laws]] 进行大规模预训练，并通过 [[RLHF]] 进行对齐优化。

## Benchmark 表现

| 基准测试 | 分数 | 备注 |
|----------|------|------|
| [[MMLU]] | 88.7% | 多领域知识理解 |
| [[HumanEval]] | 90.2% | 代码生成 |
| [[MATH]] | 76.6% | 数学推理 |
| [[GPQA]] | 53.6% | 研究生级别问答 |
| 多模态 MMMU | 69.1% | 视觉理解 |

## 多模态能力

- **视觉**：支持图像理解、图表分析、OCR，无需额外插件
- **音频**：原生语音输入输出，支持实时对话、情感表达、歌唱
- **文本**：保持 GPT-4 级别的文本推理能力
- **速度**：比 [[GPT-4 Turbo]] 快 2 倍，价格低 50%

## 定价策略

GPT-4o 是 OpenAI 首次将旗舰模型价格大幅下调的举措，input 价格仅为 [[GPT-4 Turbo]] 的一半，推动了多模态 AI 的大规模应用。通过 [[Quantization]] 和推理优化，OpenAI 实现了成本与性能的平衡。

## 影响与意义

GPT-4o 标志着多模态 AI 从"拼接式"走向"原生式"的转折点，直接影响了 [[Claude 3.5 Sonnet]]、[[Gemini 2.5 Pro]] 等竞品的多模态策略。其低延迟语音能力推动了实时 AI 助手赛道的爆发。

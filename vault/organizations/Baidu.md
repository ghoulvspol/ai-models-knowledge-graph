# Baidu

百度是中国最大的搜索引擎公司，也是中国 AI 领域的先行者。公司由李彦宏于 2000 年创立，在自动驾驶（Apollo）和大语言模型（ERNIE/文心一言）方面持续投入。

## 文心一言（ERNIE Bot）

- **ERNIE 3.5 / 4.0**：基础大语言模型
- **ERNIE Bot App**：面向消费者的 AI 对话产品，用户超过 3 亿
- **ERNIE Speed / Lite / Tiny**：不同规模的轻量模型
- 支持文本、图像、音频、视频的多模态理解与生成

## 技术积累

| 领域 | 成果 |
|------|------|
| 预训练模型 | ERNIE 系列从 2019 年开始，中国最早的大模型之一 |
| 知识增强 | 将知识图谱融入预训练过程 |
| 多模态 | 文心一格（图像生成）、文心一航（视频理解） |
| [[AI Agent]] | 文心智能体平台，支持企业构建 AI Agent |
| 自动驾驶 | Apollo 自动驾驶平台，中国 L4 级自动驾驶领导者 |

## 平台生态

- **百度智能云千帆平台**：企业级大模型开发和服务平台
- **飞桨（PaddlePaddle）**：深度学习框架，中国最大的自主 AI 框架
- **文心智能体平台**：低代码 AI Agent 构建平台
- **百度搜索 AI 改造**：搜索引擎全面集成大模型能力

## 战略地位

百度在中国 AI 领域被称为"中国的 [[Google]]"。在大模型竞争中，百度面临来自 [[Alibaba]]（通义千问）、[[DeepSeek]]、字节跳动（豆包）等的激烈竞争。ERNIE 4.0 在中文理解和生成方面保持领先，但在代码和数学推理方面与国际顶尖模型仍有差距。

## 研发投入

百度每年研发投入超过 200 亿元人民币，研发人员超过 2.5 万人。公司拥有中国最多的 AI 相关专利。

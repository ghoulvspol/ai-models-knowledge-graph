# Alibaba

阿里巴巴是中国最大的互联网公司之一，通过阿里云和通义实验室（Tongyi Lab）在 AI 大模型领域积极布局。核心产品为 Qwen（通义千问）系列模型。

## Qwen 模型系列

- **Qwen-72B / Qwen-14B / Qwen-7B**（2023）：首批开源模型
- **Qwen1.5**（2024）：改进多语言和长上下文能力
- **Qwen2 / Qwen2.5**（2024）：在 [[MMLU]]、[[HumanEval]] 等评测中表现优异
- **[[Qwen 3]]**（2025）：旗舰开源模型，支持 [[MoE]] 和 Dense 架构
- **Qwen-VL / Qwen-Audio**：多模态系列

## 技术特色

| 特性 | 说明 |
|------|------|
| 多语言能力 | 中英双语优化，支持 29+ 语言 |
| 长上下文 | 支持 128K+ token 上下文窗口 |
| 工具调用 | 原生支持 Function Calling |
| 代码能力 | 在 [[HumanEval]]、[[Codeforces]] 等评测中表现突出 |
| 数学推理 | 在 [[MATH]]、[[GSM8K]] 等评测中领先 |

## 平台与生态

- **阿里云百炼平台**：企业级模型服务平台
- **ModelScope**：开源模型社区，类似 HuggingFace
- **通义千问 App**：面向消费者的 AI 对话产品
- **钉钉 AI**：企业协作工具中的 AI 集成

## 开源策略

阿里巴巴是全球最积极的大模型开源贡献者之一。Qwen 系列在 HuggingFace 上的下载量位居前列，推动了中国开源 AI 生态的发展。开源策略帮助阿里云吸引更多开发者使用其云服务。

## 战略地位

在中美 AI 竞争背景下，阿里巴巴是中国 AI 领域的核心玩家，与 [[Baidu]]、[[DeepSeek]] 等共同推动中国大模型发展。阿里云为大量 AI 创业公司提供算力支持。

# Microsoft

微软是全球最大的科技公司之一，在 AI 领域通过 Azure AI、Copilot 和对 [[OpenAI]] 的战略投资建立了强大的市场地位。CEO Satya Nadella 领导公司全面转向 AI 优先战略。

## AI 布局

### Azure AI

- **Azure OpenAI Service**：提供 [[GPT-4o]]、[[Claude Opus 4]] 等模型的企业级访问
- **Azure AI Studio**：端到端 AI 开发平台
- **Azure ML**：机器学习训练和部署平台
- 全球第二大云服务提供商（仅次于 [[Amazon]] AWS）

### Copilot 产品线

- **Microsoft 365 Copilot**：集成于 Word、Excel、PowerPoint、Outlook
- **GitHub Copilot**：AI 编程助手，用户超过百万开发者
- **Windows Copilot**：操作系统级 AI 集成
- **Dynamics 365 Copilot**：企业 CRM/ERP AI 助手

## 与 OpenAI 的关系

微软是 [[OpenAI]] 最大的投资方，累计投资超过 130 亿美元：
- 获得 OpenAI 49% 的利润分成权
- Azure 是 OpenAI 的独家云基础设施提供商
- OpenAI 模型通过 Azure OpenAI Service 独家商业化
- 双方在技术、产品、市场上深度绑定

## 自研 AI

微软也在发展自研 AI 能力：
- **Phi 系列**（[[Phi-4]] 等）：小型高效语言模型
- **Florence**：视觉基础模型
- **Turing**：自然语言处理模型系列
- **MAI**：内部大模型研发团队

## 竞争格局

微软通过"投资 + 自研"双轮策略在 AI 领域占据有利位置。Azure AI 的企业客户覆盖金融、医疗、制造等行业，与 [[Amazon]] AWS 和 [[Google]] Cloud 形成三足鼎立之势。

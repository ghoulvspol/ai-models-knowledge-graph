# OpenAI

OpenAI 是全球领先的人工智能研究公司，由 [[Sam Altman]] 担任 CEO。公司成立于 2015 年，最初以非营利组织形式运营，2019 年转型为"有限利润"（capped-profit）结构。截至 2025 年，公司估值超过 3000 亿美元。

## 核心产品

- **GPT 系列**：从 GPT-1 到 [[GPT-4o]]，持续引领大语言模型发展
- **ChatGPT**：2022 年 11 月发布，成为增长最快的消费级应用之一
- **DALL·E**：文生图模型系列
- **Sora**：文生视频模型
- **Codex / o1 / o3**：代码生成与推理模型

## 关键技术

OpenAI 是 [[Transformer]] 架构的核心推动者，[[Alec Radford]] 主导了 GPT 系列的预训练范式。公司率先将 [[RLHF]] 大规模应用于语言模型对齐（[[Alignment]]），并推动了 [[Scaling Laws]] 的实证研究。

## 战略与合作

- **[[Microsoft]]** 是最大投资方，累计投资超过 130 亿美元，Azure 为 OpenAI 提供算力支持
- OpenAI 的模型通过 Azure OpenAI Service 向企业客户提供
- 公司在 [[AI Safety]] 领域设有专门研究团队，由 [[Jan Leike]] 曾领导对齐工作

## 研究里程碑

| 年份 | 事件 |
|------|------|
| 2018 | GPT-1 发布，确立自回归预训练范式 |
| 2019 | GPT-2，因安全顾虑延迟发布 |
| 2020 | GPT-3，175B 参数，few-shot 学习能力 |
| 2022 | ChatGPT 发布，用户破亿 |
| 2023 | GPT-4，多模态能力，通过多项专业考试 |
| 2024 | GPT-4o，原生多模态，o1 推理模型 |
| 2025 | o3/o4-mini，Codex agent，GPT-5 研发中 |

## 争议与治理

2023 年 11 月，Sam Altman 短暂被董事会解职后迅速复职，引发公司治理结构改革。公司面临来自 [[Anthropic]]、[[Google DeepMind]] 等竞争对手的激烈竞争。

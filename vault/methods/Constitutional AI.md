# Constitutional AI

Constitutional AI（CAI，宪法AI）是 [[Anthropic]] 提出的 AI 对齐方法，通过一组"宪法原则"指导模型行为，减少对人类标注的依赖。它是 Claude 系列模型安全性的核心技术。

## 核心思想

传统 [[RLHF]] 依赖大量人类标注，存在：
- 标注成本高
- 标注者偏见
- 难以扩展

Constitutional AI 的解决方案：
1. 定义一组清晰的行为原则（"宪法"）
2. 让 AI 自我批评和修正
3. 使用 AI 反馈训练奖励模型（RLAIF）
4. 减少对人类标注的依赖

## 训练流程

### 阶段 1：监督学习（自我修正）

1. 给模型一个有害的 prompt，生成回答
2. 要求模型根据宪法原则批评自己的回答
3. 要求模型根据批评修正回答
4. 用修正后的回答作为训练数据进行 SFT

### 阶段 2：强化学习（RLAIF）

1. 让模型对多个回答进行排序
2. 排序基于宪法原则
3. 使用 AI 偏好数据训练奖励模型
4. 用 [[RLHF]] 优化模型

## 宪法原则示例

```
1. 选择最有帮助、最准确、最无害的回答
2. 选择最不鼓励暴力或非法行为的回答
3. 选择最尊重人类尊严和权利的回答
4. 选择最不包含有害刻板印象的回答
5. 选择最诚实、最不误导的回答
```

## 与 RLHF 的对比

| 特性 | [[RLHF]] | Constitutional AI |
|------|---------|-------------------|
| 反馈来源 | 人类标注 | AI 自我评估 |
| 扩展性 | 受限于标注团队 | 高度可扩展 |
| 一致性 | 受标注者差异影响 | 原则驱动，更一致 |
| 成本 | 高（人工标注） | 较低 |
| 透明度 | 黑箱 | 原则可审查 |
| 效果 | 长期验证 | 接近 RLHF |

## 行业影响

Constitutional AI 对 AI 对齐领域的影响：
- **RLAIF**：证明 AI 反馈可以替代人类反馈
- **可扩展对齐**：为大规模对齐提供了可行路径
- **透明度**：原则比标注更可审查和修改
- **[[Anthropic]] 的核心技术**：Claude 系列模型的基础

## 变体与演进

- **Collective Constitutional AI**：众包宪法原则
- **基于角色的宪法**：不同场景使用不同原则
- **动态宪法**：根据上下文调整原则
- **多语言宪法**：跨文化对齐原则

## 局限性

- 宪法原则的制定仍需人类参与
- AI 的自我评估可能有盲点
- 原则之间的冲突需要权衡
- 难以覆盖所有边缘情况

# Distillation

Distillation（知识蒸馏）是将大模型（教师模型）的知识转移到小模型（学生模型）的技术。它由 [[Geoffrey Hinton]] 等人于 2015 年提出，是模型压缩和效率优化的核心方法。

## 核心思想

- 教师模型的输出包含"软知识"（类别间的相对关系）
- 学生模型不仅学习正确答案，还学习教师的"思维方式"
- 软标签（Soft Labels）比硬标签（Hard Labels）包含更多信息

## 蒸馏类型

| 类型 | 说明 | 应用 |
|------|------|------|
| 输出蒸馏 | 学习教师的输出分布 | 最常用 |
| 特征蒸馏 | 学习教师的中间表征 | 计算机视觉 |
| 关系蒸馏 | 学习样本间的关系 | 对比学习 |
| 在线蒸馏 | 教师和学生同时训练 | 大规模训练 |

## 大模型时代的蒸馏

在大语言模型时代，蒸馏的应用方式发生了变化：

### 推理蒸馏

- 从强推理模型（如 [[DeepSeek R1]]）蒸馏推理能力
- 学生模型学习教师的 [[Chain of Thought]] 过程
- 小模型也能获得强大的推理能力

### 数据蒸馏

- 使用大模型生成训练数据
- 小模型在生成的数据上训练
- 代表：Alpaca（用 [[GPT-4o]] 数据训练 LLaMA）

### API 蒸馏

- 通过 API 调用获取教师模型输出
- 在本地训练学生模型
- 法律和伦理争议

## 实际案例

| 案例 | 教师 | 学生 | 效果 |
|------|------|------|------|
| [[Phi-4]] | GPT-4 | Phi-4 小模型 | 小模型超越预期 |
| DistilBERT | BERT | DistilBERT | 60% 大小，97% 性能 |
| Gemma 3 | [[Gemini 2.5 Pro]] | Gemma 3 | 开源高效模型 |
| DeepSeek-R1-Distill | DeepSeek R1 | 小模型 | 推理能力大幅提升 |

## 与 Quantization 的关系

蒸馏和[[Quantization]]常结合使用：
1. 先蒸馏得到小模型
2. 再量化降低推理成本
3. 两者效果叠加

## 行业价值

- **成本降低**：小模型推理成本远低于大模型
- **延迟优化**：更快的响应速度
- **端侧部署**：让 AI 在手机等设备上运行
- **民主化**：让小团队也能拥有强大 AI 能力

# Post-training

Post-training（后训练）是在预训练模型基础上进行的所有后续训练步骤的总称。它将通用语言模型转化为有用、安全、符合人类偏好的助手。

## 后训练流程

```
预训练模型 → SFT → 奖励模型训练 → RLHF/DPO → 安全对齐 → 最终模型
```

### 阶段 1：监督微调（SFT）

- 使用高质量的指令-回答对训练模型
- 教会模型遵循指令和对话格式
- 数据来源：人工标注、AI 辅助生成

### 阶段 2：偏好对齐

- **[[RLHF]]**：训练奖励模型 → PPO 优化
- **[[DPO]]**：直接从偏好数据优化
- **[[Constitutional AI]]**：基于原则的自我修正
- 目标：让模型更安全、更有帮助、更诚实

### 阶段 3：安全训练

- 拒绝有害请求
- 减少幻觉和错误信息
- 处理对抗性输入（红队测试）

## 后训练技术栈

| 技术 | 作用 | 阶段 |
|------|------|------|
| [[Fine-tuning]] | 适配特定任务 | SFT |
| [[RLHF]] | 人类偏好对齐 | 偏好对齐 |
| [[DPO]] | 简化的偏好对齐 | 偏好对齐 |
| [[Constitutional AI]] | 原则驱动对齐 | 安全训练 |
| Red Teaming | 对抗性测试 | 安全评估 |
| [[Chain of Thought]] | 推理能力训练 | 能力增强 |

## 各公司实践

### [[OpenAI]]

- ChatGPT：SFT + RLHF 的经典流程
- o1/o3：在后训练中融入长链推理
- 使用人类标注员团队进行数据标注

### [[Anthropic]]

- [[Constitutional AI]]：减少对人类标注的依赖
- RLAIF：使用 AI 反馈替代人类反馈
- 可解释性指导的安全训练

### [[Meta AI]]

- Llama 2/3：开源后训练流程
- [[DPO]] + [[RLHF]] 混合训练
- 安全微调的数据公开

### [[DeepSeek]]

- DeepSeek R1：纯 [[RLHF]] 训练推理能力（跳过 SFT）
- 创新的 GRPO 算法
- 证明了 RL-only 路径的可行性

## 后训练的成本

| 阶段 | 计算成本 | 数据成本 |
|------|---------|---------|
| SFT | 低 | 中（人工标注） |
| 奖励模型 | 中 | 高（偏好标注） |
| RLHF/DPO | 中-高 | 中 |
| 安全训练 | 中 | 高（红队测试） |

## 重要性

后训练决定了模型的"性格"和实际可用性：
- 预训练模型是"原材料"
- 后训练将原材料变成"产品"
- 不同的后训练策略产生不同风格的模型

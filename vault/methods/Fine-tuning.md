# Fine-tuning

Fine-tuning（微调）是在预训练模型基础上，使用特定领域或任务数据进行进一步训练的技术。它是将通用大模型适配到具体应用场景的核心方法。

## 微调类型

| 类型 | 说明 | 代表方法 |
|------|------|---------|
| 全参数微调 | 更新所有模型参数 | 标准 SFT |
| [[LoRA]] | 低秩适配，仅训练少量参数 | 参数高效微调 |
| QLoRA | 4-bit 量化 + LoRA | 显存友好 |
| Adapter | 在模型中插入适配层 | 参数高效微调 |
| Prefix Tuning | 仅优化前缀向量 | 参数高效微调 |

## 训练流程

1. **数据准备**：收集高质量的指令-回答对
2. **模型选择**：选择合适的基础模型（如 [[Llama 4 Scout]]、[[Qwen 3]]）
3. **训练配置**：学习率、batch size、epoch 数
4. **训练执行**：在 GPU 集群上运行训练
5. **评估验证**：在验证集上评估效果
6. **部署上线**：模型量化后部署

## 关键技术

### 指令微调（Instruction Tuning）

- 使用指令格式的数据训练模型遵循指令
- 提升模型的通用对话能力
- [[OpenAI]] 的 InstructGPT 是典型案例

### 参数高效微调（PEFT）

- [[LoRA]]：低秩矩阵分解，仅训练 0.1% 参数
- QLoRA：4-bit 量化 + LoRA，单 GPU 可微调 65B 模型
- 显存需求降低 10-100 倍

## 行业应用

- **垂直领域**：医疗、法律、金融领域的专业模型
- **企业定制**：基于企业数据训练专属助手
- **语言适配**：增强特定语言能力
- **安全对齐**：通过 [[RLHF]] 和 [[DPO]] 进行安全微调

## 平台支持

- **OpenAI Fine-tuning API**：[[OpenAI]] 提供的托管微调
- **Hugging Face**：开源微调工具链
- **Amazon SageMaker**：[[Amazon]] 的微调平台
- **Google Vertex AI**：[[Google]] 的微调服务

## 注意事项

- 数据质量比数据量更重要
- 过拟合是主要风险
- 需要防止灾难性遗忘
- 评估指标需要与业务目标对齐
